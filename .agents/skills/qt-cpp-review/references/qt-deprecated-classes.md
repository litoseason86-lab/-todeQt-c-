# 废弃 API 与替换建议的核实

- 先确定项目的 Qt 最低版本与实际构建版本，查该版本文档中的 Deprecated/Obsolete 标记。
- 上游框架偏好的类型不等于其他类型已废弃；标准库容器、智能指针和 `std::optional` 并非通用禁用项。
- 替换 API 前核对所有权、返回值、编码、时间单位和失败语义，不能只换名称。
- 编译器告警和官方迁移说明可作证据；扫描器的 DEP/PAT 命中仅用于定位候选。
- 性能建议需要调用频率与数据量支持；例如 `value_or()` 参数会先求值，但参数便宜时未必值得改写。
- 不在只读审查中执行迁移；报告具体版本、旧行为和建议路径。
