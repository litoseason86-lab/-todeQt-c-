# Qt 框架开发的附加边界

仅审查 Qt 库本体或承诺二进制兼容的公共库时读取。普通应用不使用这套发布约束。

- 明确支持的 Qt/编译器/平台版本和 ABI 承诺，再判断布局、虚函数、导出符号变化是否破坏兼容。
- 公共头文件避免泄露不稳定实现依赖；私有实现和符号可见性按该库现有规范处理。
- QML 暴露的新类型、属性和方法检查模块版本与旧客户端可见性，不凭模板机械添加 revision。
- 新增依赖检查许可证、平台可用性与下游链接影响。
- 公共 API 的所有权、错误、线程和生命周期契约需可解释且可验证。
- 框架自身的命名、头文件排序和提交格式来自其项目规则，不复制到普通应用。
