# 静态资源与 Shader

- 按项目已有方式将图片、字体、翻译和其他资产加入模块或 Qt 资源目标。
- 明确源文件路径、构建产物路径和运行时 URL；目录重排后检查 alias/prefix 与引用是否仍一致。
- 对已存在的 `.qrc` 不做无关迁移；新增 QML 模块优先由模块 API 管理 QML 文件。
- Qt 6 ShaderEffect 使用兼容的预编译 shader 资源；核实项目 ShaderTools 配置及最终 `.qsb` URL。
- shader 预编译产物由构建生成，不直接修改；源码改动后验证相应资源可加载。
- 资源在源码中存在不等于已打包；使用现有资源测试或最小加载验证检查最终包内路径。
- 翻译更新、资源压缩和安装规则仅在本次任务需要时调整。
