# 基本目标边界

仅新增工程或修复启动配置时读取；既有工程不按模板重写。

- 先确定项目实际最低 CMake/Qt 版本和 C++ 标准，不无故提高最低版本。
- 新工程可用 `qt_standard_project_setup()` 设置常用自动处理；它不代替 C++ 标准和所有资源配置。
- 标准、AUTOMOC 等变量要在相关目标创建前生效，也可以用对应目标属性控制。
- 已有项目手工启用 AUTOMOC/AUTOUIC 是有效方式，不为统一外观重复配置。
- Qt 库依赖通过目标传递；不要手写 moc、ui、qrc 生成文件列表。
- 平台包属性、入口文件和启动资源沿用工程现有约定。
