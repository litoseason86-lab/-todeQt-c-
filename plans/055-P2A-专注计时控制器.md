## 设计

### 依赖与装配

```cpp
FocusSessionController(FocusTimer* timer, TaskManager* tasks, AppSettings* settings,
                       PendingDeletion* pendingDeletion, QObject* parent = nullptr);
```

- `main.cpp`：在 `PendingDeletion` 之后、`QQmlApplicationEngine engine;` 之前创建，设上下文属性 `focusSessionController`。
- `main.qml`：给 MainWindow 加 `focusSessionControllerRef`，写法照旁边几行。
- MainWindow 把它传给 FocusView；FocusView 新增 `property var focusSessionControllerRef: null`。

### 接口

名字可以按相邻代码的习惯调整，**语义必须照下面**。返回 `QVariantMap` 是为了 QML 和将来的桥接层都能直接用。

| 规则 | 接口 | 语义（照现有 QML 逐条移过来） |
| --- | --- | --- |
| 2 | `QVariantMap planTaskEntry(int taskId, const QString& title) const` | 返回 `{kind, usePomodoro, autoStart, title}`，`title` 是 trim 后的标题。<br>`kind` 的判定：<br>• `invalid`：taskId ≤ 0 或标题为空；界面提示「任务信息无效，无法开始计时」。<br>• `returnToCurrent`：计时中且 currentTaskId == taskId；不看记住的模式。<br>• `confirmSwitch`：有活动会话或 phase ≠ 0。<br>• `apply`：其余情况。<br>`usePomodoro = settings.lastMode == 1 \|\| !timer.freeTimingAllowed`；`autoStart = settings.quickStartEnabled`。 |
| 6 | `QVariantMap switchConsequence() const` | 返回 `{kind, minimumMinutes}`。`kind` 的判定：<br>• phase 为 2 或 3（休息段）：`restKept`；<br>• 已用秒数 < minimumValidMinutes×60：`notSaved`；<br>• 其余：`saved`。<br>文案留在 QML。 |
| 6 | `QVariantMap captureSwitchSource() const` / `QString stopForSwitch(const QVariantMap& source)` | 打开确认框时记下 `{taskId, mode, phase}`。确认时按顺序判断：<br>1. 计时器的这三项与记下的不一致：`stateChanged`；<br>2. 需要超长确认：`needsLongFreeConfirmation`；<br>3. `stopFocus()` 失败：`stopFailed`；<br>4. 以上都不是：`stopped`。 |
| 6 | `QVariantMap planModeSwitch(int selectedTaskId, const QString& selectedTitle) const` | 计时器忙（有活动会话或 phase ≠ 0），并且有可继承的任务时返回 `{kind: "confirmSwitch", taskId, title}`，这条路不自动开始。可继承的任务：计时器有当前任务就用它，否则用选中项。<br>其余情况返回 `{kind: "pageOnly"}`。<br>「要切的模式就是当前页签」的判断属于页面状态，留在 QML。 |
| 7 | `int freeTimerWarningHours() const` | 设置值在 1–24 之间时取整，否则用 8。 |
| 7 | `bool needsLongFreeStopConfirmation() const` | 有活动会话、mode == 0，且 `timer.requiresFreeFocusStopConfirmation(freeTimerWarningHours())`。 |
| 4 | `QVariantMap endCurrent()` | 返回 `{result, kind, discarded, error}`。<br>`result` 取值：`none`（没有会话且 phase == 0）/ `needsConfirmation` / `ended` / `failed`。<br>按计时器的真实模式分发：<br>• 主动休息（mode 2、phase 3）：调 `stopFocus`；<br>• 番茄（mode 1）：phase ≠ 0 或有活动会话时调 `stopFocus`，成功后 `resetPomodoroCount()`；<br>• 自由（mode 0）：先判断超长，需要确认就返回 `needsConfirmation`，否则调 `stopFocus`。<br>失败文案沿用现有的三句：「结束休息失败，请重试」「番茄结束失败，请重试」「专注保存失败，请重试」。<br>`discarded`：停止过程中同步收到了 `sessionDiscarded`，即不足 3 分钟未计入。 |
| 7 | `QVariantMap finishLongFree(bool recordSession, int correctedSeconds)` | 返回 `{ok, error}`。<br>• 记录且修正秒数 > 0：调 `stopFreeFocusWithDuration`；<br>• 记录且不修正：调 `stopFocus`；<br>• 不记录：调 `discardFreeFocus`。<br>失败文案沿用「专注保存失败，请重试」「专注丢弃失败，请重试」。 |
| 5 | `QVariantMap autoStartCandidate(int selectedTaskId, const QString& selectedTitle) const` | 返回 `{id, title, selectionStale}`，没有候选时 id 为 -1。按顺序判断：<br>1. 选中项有效（编号 > 0、标题非空），且按编号回查确实存在：用它。<br>2. 选中项回查不到：`selectionStale = true`（界面清掉选中），继续往下。<br>3. 取逻辑今日第一个未完成任务，跳过 `pendingDeletion.taskId`（撤销窗口里的那条）。<br>候选范围只是逻辑今日。 |
| 8 | `int createTodayTask(const QString& title)` | 标题 trim 后为空返回 -1。否则 `createTask(trim 后的标题, LogicalDay::today(dayStartHour), -1, 0, "")`，返回新编号，失败返回 -1。不按标题反查。 |
| 3 | `QVariantMap handleTaskCompleted(int taskId)` | 返回 `{focusResult, discarded, error}`。只在「有活动会话且 currentTaskId == taskId」时调 `endCurrent()`，并把它的结果原样带回。<br>其余情况返回 `none`：已完成的任务允许再练一轮，那种计时不能停；番茄休息段没有会话，休息照常进行。 |

### QML 侧留下什么

- **FocusView**：
  - 选中任务、模式页签、时长面板；
  - 确认框（含超长确认框）和 `pendingSwitch` / `pendingLongFreeAction` 状态机；
  - 跳页信号（`focusEnded`、`manualRestEnded`）、`errorText`、`justCompletedPhase`、`cancelAutoAdvance`；
  - 「开始」本身：`startFreeFocus` / `startPomodoro` 仍直接调计时器，并记住 `lastMode`。

  这些都是页面状态和界面效果。原来做判断的地方改成调控制器，再按返回的 `kind` / `result` 执行。
- **MainWindow**：
  - 提示条文案、`endingFocusInPlace` 之类的界面标志；
  - `requestLongFreeFocusStop`（切到专注页弹确认）。

  `startFocusForTask`、`endFocusInPlace`、`handleTaskCompletedByUser` 改成先问控制器，再做界面动作。

## 风险

- 三个 QML 测试文件共约 175 个用例，改写工作量大，容易误删覆盖，靠对照表兜住。
- `sessionDiscarded` 是在 `stopFocus` 过程中同步发出的。控制器要在调用前接上、调用后断开，用 `qScopeGuard` 保证断开。
- 有些现有行为看起来像缺陷，保持原样，写进报告，不顺手改。
