## 定稿要点（以设计稿和 canvas notes 为准）

### 外壳

- **宽窗顶部标签栏**：只放五个常用页面直达——今日任务、专注、本周、今日专注、仪表盘。不再出现「页面」「应用」两个分组下拉；其余页面从侧栏进。用 iPadOS 26 SDK 实测能做到的方式（标签可见性、分组放置）实现，做不到就停下报告，不要自己发明一套顶部栏。
- **窄窗底部标签栏**：今日任务、专注、**记录**（进今日专注页）、仪表盘、更多。本周计划挪进「更多」。标签文字就是「记录」，页面标题仍是「今日专注」。保持 F2 的不闪退写法（标签集合稳定、选中值只取当前尺寸下存在的标签）。
- **侧栏**：顶部四个摘要块——今日任务（未完成数）、专注计时（今日已专注或正在计时的时间）、本周待办（数）、**主目标倒计时**（主目标名称 + 剩余天数，点了进目标倒计时页；没有主目标时显示「目标倒计时」和「—」）。页面列表里加入「知识缺口」，后面带到期数；「目标倒计时」那行不再写天数；废纸篓、设置固定在底部。
- **底部计时条**：F2 已改成只在计时（含暂停）时出现；R1 再加一条：停在专注页时不显示（专注页自己就是计时界面）。
- 宽窗下页面的「记一笔」「更多」等按钮在页头右上，规则见 row4note；本计划只管外壳，不改各页内容。

### 外观（设置 → 外观）

- 上面一组「系统外观」：跟随系统 / 浅色 / 深色——就是 iPadOS 原生的明暗和默认的系统背景色；下面一组「主题」：七个主题（暖色、粉色、烟雨江南、雪岭剑影、星空、雨夜窗景、月夜山影）。
- **两组互斥**：选了任一主题，上面三个都不亮；选了上面任一个，主题都不选。一共只有一个选中项。
- 选了主题：配色按 Mac 主题走（主题自带明暗：星空、雨夜、月夜是深色，其余浅色；页面底色取主题的 base，卡片与文字用对应日 / 夜令牌）；「使用壁纸」打开时铺该主题的壁纸。
- 选了系统外观：用系统背景色，`preferredColorScheme` 分别为跟随 / 浅 / 深；不铺壁纸，「使用壁纸」开关灰掉。强调色仍用焦糖色（沿用「蓝改焦糖」的定案）；如果用户之后要系统蓝，只改这一处。
- 存储：新增本机键 `ipad/appearance`，取值 `system | light | dark | theme`；主题 id 沿用 `AppSettings::backgroundTheme`（本来就是每台设备各自的设置）；「使用壁纸」沿用 `ipad/useWallpaper`。都不进同步。
- 老用户迁移（无键时）：`ipad/useWallpaper` 为真 → `theme`（沿用当前 backgroundTheme）；否则 → `system`。迁移只在读取时推导，第一次写入时才落键。
- 壁纸与主题名单仍由 `tests/ipad_theme_gate.py` 核对与 `Theme.qml` 一致；主题的 base 色、明暗也要纳入同一门禁，不在 Swift 里另抄一份不受检查的名单。

### 设置页

- 宽窗：同一页里左边分组、右边详情（F2 已修好导航）；窄窗推入。
- 「通用」：专注（专注时长、休息时长、长休息、自动开始休息、自动开始下个番茄、快速开始、自由计时超时确认）、提示（阶段结束提示音）、日期（一天从几点开始）、个人（昵称），全用系统表单控件（步进器、开关、菜单）。
- 「同步与日志」：启用同步、同步文件夹 + 重新选择、状态（已同步 / 上次同步 / 待同步）、立即同步、同步日志（N）推入子页。
- 「外观」：见上。
- 科目、每日例行、侧栏顺序、备份与恢复、导出：沿用同一种表单写法，内容不变。
- 不放说明性文字；写入失败回到旧值并显示服务给的原因（P4-5 已有，保持）。

## 需要补的接口

- `PTShellBridge` 快照加主目标：名称、剩余天数、有无（来自 `CountdownService::primaryGoal`，跟随 `primaryGoalChanged` 刷新）。天数由服务给，Swift 不算日期。Qt Test 覆盖：有主目标、无主目标、主目标变化发出刷新。
- `PTShellBridge` 读写 `ipad/appearance`（照 `ipad/useWallpaper` 的写法：写失败还原、成功才发变化）。Qt Test 覆盖：无键时的迁移推导、写入与读回、写失败还原。
- Swift 侧协议、适配器、替身同步加。

## 步骤

1. **接口**：主目标快照、`ipad/appearance` 读写与迁移；Qt Test 与 swift 替身。
2. **外壳**：顶部五个直达、窄窗「记录」标签与「更多」、侧栏摘要块与知识缺口入口、专注页不显示计时条。Store 测试覆盖标签映射（窄窗里今日专注是根标签、本周进「更多」）和摘要块内容（有 / 无主目标）。
3. **外观**：系统外观与主题互斥（Store 测试：选主题清掉系统外观、选系统外观清掉主题、壁纸开关只在主题下可用、迁移结果）；主题配色与壁纸；门禁纳入 base 色与明暗。
4. **设置页**：通用、同步与日志、外观三页按稿重排；其余分组统一表单写法。
5. **收尾**：文档、全量验证、自查颜色与无障碍、清理构建目录。
