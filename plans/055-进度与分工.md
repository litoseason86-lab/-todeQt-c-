## 并行约定（每个执行者都要遵守）

### 工作区与分支

- 每份子计划一个 git worktree、一个分支，都从最新的 `feat/ipad-native` 拉：
  `git -C /Users/zerionlito/code/番茄todo worktree add /Users/zerionlito/code/番茄todo-055-<编号> -b feat/055-<编号> feat/ipad-native`
- 只在自己的 worktree 里改代码和提交；不切换主仓库 `/Users/zerionlito/code/番茄todo` 的分支，也不在那里改文件。
- 第 2 波开工前，协调者先把依赖合入 `feat/ipad-native`，执行者再从那里拉分支。

### 构建目录

多个工作区不能共用 `~/pt-audit`：它绑定唯一的源码目录。按 AGENTS.md「确需隔离用 `~/pt-<用途>`、用完当场 `rm -rf`」，每份子计划用自己的目录：

| 用途 | 目录 | 说明 |
| --- | --- | --- |
| Mac 构建与全量 ctest | `~/pt-055-<编号>` | 配置：`~/Qt/6.10.3/macos/bin/qt-cmake -B ~/pt-055-<编号> -S <自己的 worktree> -DPOMODORO_TODO_DEPLOY_LOCAL=OFF` |

### 提交、合并与验收

- 执行者只提交到自己的分支：每条规则或每个步骤一个提交，中文说明，写清验证结果。不合并、不推送。
- 协调者验收后，按「协调者验收清单」合并到 `feat/ipad-native`。冲突由协调者解决，解决后在 `feat/ipad-native` 上重跑全量 ctest；动过 iOS 部分的还要做 iOS 不签名编译。
- 合并回 `main`、推送，仍只在用户明确要求时做，照 AGENTS.md 与 `.agents/skills/merge-to-main/SKILL.md`。

### 真机

- 执行者不装机、不启动应用、不启动模拟器。
- 需要在 iPad 上确认的项，写进报告的「需要用户在 iPad 上确认」一节。由用户安排装机时间：同一时间只有一个人用 iPad。

### 报告格式（所有子计划共用）

1. 做了什么：对照计划的步骤逐条写。
2. 改了哪些文件。
3. 提交列表（提交号与一句话）。
4. 实际运行的命令和结果，含构建告警数、全量 ctest 结果、变异验证结果；没运行的标「未运行」，不写「应该能通过」。
5. 与计划的偏离和原因。
6. 未完成项、阻碍、已知问题、顺手发现但没处理的问题。
7. 需要用户在 iPad 上确认的项（没有就写「无」）。

### P4 通用约定（P4-1 至 P4-5 都适用）

- **分层**：
  - Store 放在 `src/ui/ipad/Sources/IPadCore/Stores/`，写成 `@MainActor @Observable`，经 IPadCore 里的协议调用桥接，测试时换成替身；
  - 视图放在 `Sources/IPadUI/Pages/<页面>/`；
  - 跨页组件放在 `Sources/IPadUI/Components/`。
- **不写业务判断**：
  - 日期是不是「今天」「逾期」「未来」、统计归属、计时结算、冲突判断，都由服务或桥接给结果；
  - Swift 不比较日期，不做加总；
  - 逻辑今日一律从 P3B 的逻辑日桥接取。
- **读取与失败**：
  - 读取失败保留上一份数据，显示重试，不当成空状态；
  - 写入失败显示服务给的原因，表单保留输入。
- **编辑与刷新**：
  - 编辑只交改过的字段；
  - 编辑或拖动任务期间持有 P3B 的交互令牌，期间收到的刷新延后到令牌释放时补一次；
  - 收到逻辑日变化信号时重读。
- **删除**：
  - 任务、专注记录一律经 `PendingDeletionStore`，可以撤销；
  - 其它对象照 Mac 的确认方式。
- **外观**：
  - 颜色只用 `ThemeColors` 的语义色；
  - 用系统组件。自绘只限三处：计时圆环、课表网格、月历投入条；
  - 动画响应「减少动态效果」，图标按钮都有无障碍名称；
  - 不写 Mac 上已经删掉的说明性文字。
- **显示格式**：用 Swift 重写对应的 `*.js` 格式函数，`swift test` 用 P2B 在 `tests/fixtures/calibers/` 的对照表逐条断言；表里没有的输入不自己发明口径。
- **本机界面状态**（筛选、展开、上次选的分段）：
  - 只给 Swift 自己用的，存 `UserDefaults`，键名 `ipadui.<页面>.<项>`；
  - 不要和 QSettings 的键混用。要让 C++ 也读到的，经桥接写 QSettings 的 `ipad/` 分组，照 P3A 的 `selectPage`。
- **测试**：SwiftUI 视图不做自动测试。每个 Store 的业务语义，对照 Mac 的 QML 用例写成 `swift test`，报告附对照表。
- **页面之间的跳转**一律经 `ShellStore` 切页，不在页面里直接持有别的页面。
