## 问题与证据

### 1. 窄窗口点底部标签栏的页面就闪退

- 用户在小屏（窄窗口，底部是标签栏）点标签栏里的页面，应用直接退出。
- iPad 上 10-10 19:34–19:35 的 6 份崩溃日志（协调者拉下 4 份）全是 `SIGABRT`，抛在系统的标签栏控制器里：
  - 三份：`-[UITabBarController _tabs_rebuildTabBarItemsAnimated:]` → `-[__NSArrayM insertObject:atIndex:]` 抛异常（重建标签项时往数组插入越界或插入空值）；
  - 一份：`-[UITabBar _didSelectButtonForItem:]` → `_tabBarDidChangeSelectionToItem:` → `_viewControllerForTabBarItem:` 断言失败（点中的标签项找不到对应页面）。
- 协调者读代码看到的可疑点（执行者要逐个核实，不要只照这里改）：
  - `ShellRootView` 里「更多」标签用 `if sizeClass == .compact { Tab(...) }` 按尺寸动态增删；
  - 点标签 → `onChange(of: tab)` → `store.select` → `onChange(of: store.selection)` → `syncSelection()` 又改 `tab`：系统还在处理这次点击时标签结构或选中值又变了；
  - `syncSelection` 用 `PageID.primary`（今日、专注、本周、仪表盘）判断窄窗口是否留在主标签，选中值可能指向窄窗口里不存在的标签（`.sidebarOnly` 的页面、知识缺口）；
  - 「页面」分组的标签来自 `store.sidebarPages`，快照刷新时这个数组是否每次都生成新值、引起标签重建，也要核实。

### 2. 宽窗口设置页切不了分组

- `SettingsPage` 在宽窗口用 `NavigationSplitView`，它又被 `pageView` 包在 `NavigationStack` 里、外面还有带侧栏的 `TabView`：分栏视图嵌在导航栈里，左侧列表的选中驱动不了右侧。
- 右侧详情的标题写死成「通用」。
- 「外观」是单独一个分组；用户报的「外观只有默认、不能切换」很可能就是进不了这一栏。修好导航后核对：主题选择器写入后，外壳的壁纸和配色确实跟着变（`ShellStore` 快照在外观变化时刷新）。

### 3. 底部玻璃不计时也显示、而且是空白

- `ShellRootView` 用 `.tabViewBottomAccessory { if store.snapshot.hasTimer { miniTimer } }`。iOS 26 起这个容器本身一直显示，只是里面没内容，于是宽窗口最下面一直有一条空白玻璃。

## 修法

1. **标签栏**：
   - 标签集合不随尺寸、快照动态增删或重排：「更多」标签始终声明，宽窗口用系统的可见性控制隐藏（例如 `.defaultVisibility(.hidden, for: .sidebar)` 一类，按实测选择）；
   - 选中值只取当前尺寸下真实存在的标签：窄窗口里非主标签页一律落到「更多」并把页面压进它的导航路径，宽窗口落到对应页面；这个映射写成 `ShellStore`（或独立的纯函数）里可测的逻辑；
   - 不在 `onChange(of: tab)` 的同一轮里再写回 `tab`；需要改写时推到下一轮，并保证不会来回振荡；
   - `sidebarPages` 等用于 `ForEach` 的数组内容不变时不产生新值（相等就不赋值）。
2. **设置页**：宽窗口不要在导航栈里嵌 `NavigationSplitView`。改成同一个导航栈里左列表、右详情的两栏布局（`HStack` 或系统等价写法），左侧选中直接决定右侧；窄窗口保持推入。右侧标题跟所选分组。
3. **底部计时条**：不计时时不显示这个容器（用 `tabViewBottomAccessory(isEnabled:)` 或等价方式，以 iPadOS 26 可用的 API 为准；有可用性分支就写明），计时开始时出现、结束时消失。

## 步骤

1. **窄窗闪退**：先写 swift test 固定「尺寸 + 目标页 → 标签选中值与更多路径」的映射，修复前失败；再改 `ShellRootView` 与 `ShellStore`。变异：窄窗口把非主标签页直接作为选中值，用例失败。
2. **设置页导航**：把「选中分组 → 右侧内容与标题」能下沉的部分放进 Store 并测；改视图结构。变异：选中不更新详情，用例失败。
3. **底部计时条**：显示条件写成 Store 的计算属性并测（有计时显示、无计时不显示、计时结束后隐藏）；视图按它控制容器。变异：条件恒真，用例失败。
4. **收尾**：`docs/业务规则.md`「iPad 原生界面」末尾追加三条现状说明；全量验证；清理构建目录。
