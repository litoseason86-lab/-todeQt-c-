# 073 界面审查修复

2026-11-11 界面审查发现 9 处问题（2 处离屏实测确认，7 处读代码发现），本计划全部修复。不升 schema、不改同步格式。

## 问题与方案

| 编号 | 问题 | 方案 |
| --- | --- | --- |
| U1 | Mac 提示条不设宽度上限，长标题把「撤销」挤出窗口 | 提示条最宽为窗口宽减两侧 24；正文最多两行、超出省略，动作按钮始终在条内 |
| U2 | Mac 配对码显示后折成 4 行，溢出 52 高的框 | 框高跟随文字：`max(52, 文字高 + 上下内边距)` |
| U3 | 同步切换的错误文字只在下一次切换时清空，关掉弹窗或表单后仍挂着 | `SyncController` 加 `clearTransportProblem()`（切换中不清）；Mac 建空间弹窗打开、关闭和设置窗关闭时调用；iPad 打开、取消配对码表单时调用 |
| U4 | iPad 同步设置页的提示写进去后从不清空 | 每个用户动作开始时清空；同步设置页和日志详情页出现时清空 |
| U5 | iPad 同步关闭时「状态」第一行为空 | 第一行改显示 `summaryText`，`statusText` 非空才显示 |
| U6 | iPad 同步关闭时「立即同步」仍可点 | 同步未开启时置灰，与 Mac 一致 |
| U7 | iPad 备份时间直接显示原始 ISO 串 | IPadCore 加格式化，显示 `yyyy-MM-dd HH:mm`（本地时间，与 Mac 一致），解析不了原样显示 |
| U8 | iPad 备份遮罩的旁白写死「正在恢复数据」 | 旁白与画面都用 `operationText`，空时退回「正在处理数据」 |
| U9 | Mac 建同步空间弹窗按回车不提交 | 地址框回车跳到口令框，口令框回车提交 |
