## 2. 本轮补齐：数据与平台

- **备份偏好解码**：解码前只允许布尔、整数、双精度数和字符串，并校验字符串声明长度、负载长度与尾部字节。嵌套容器和自定义类型无法进入通用 QVariant 递归解码。新增测试走生产使用的异步恢复入口，覆盖 6000 层嵌套、伪造长度和尾部垃圾。
- **虚拟表检查**：改用 SQLite 解析后的表类型，同时拒绝虚拟表及其影子表；添加 SQL 注释不能绕过。用带注释的 FTS5 表验证拒绝路径。
- **知识缺口转任务**：来源说明计入备注长度，超限回滚并保留缺口原文，不再截断。
- **知识缺口搜索**：`%`、`_`、`!` 按字面搜索；修正“同名占位符只绑定第一处”的错误注释。
- **v5 迁移**：拒绝未知列重建时先回滚事务，再恢复外键开关。
- **CSV**：输出 UTF-8 字节序标记；具有公式前缀的文本以单引号保护。测试检查实际导出字节和公式文本。
- **菜单栏结束**：收尾成功后重置番茄轮次，失败仍保留会话供重试。
- **周复盘**：按各科目余秒分配显示分钟的取整差额，分项之和等于合计，原始秒数不变。
- **数据库启动失败**：显示独立 QML 错误窗口，不加载业务界面；离屏验证路径只写日志并退出。资源清单验证覆盖新页面。

备份解码采用预校验，是因为 [Qt 官方说明 QDataStream 不适合直接处理损坏输入](https://doc.qt.io/qt-6/qdatastream.html#corruption-and-security)。表类型检查依据 [SQLite 的 table_list 定义](https://www.sqlite.org/pragma.html#pragma_table_list)。

## 6. 验收复核补修（2026-09-16，第二轮）

对上述修复逐条复核，用变异测试确认「改了能被测出来」。以下是复核发现并已修掉的问题。

### 6.1 修复本身的缺陷

- **菜单栏「停止」把番茄轮次清过头**：上一轮改成「收尾成功就 `resetPomodoroCount()`」，但 `canStop` 对自由专注和主动休息同样为真，于是从菜单栏结束一段自由专注会把攒下的连续番茄数清零——专注页的 `endFreeFocus` / `endManualRest` 和仪表盘都不会。改为在 `stopFocus()` 之前记下模式（`stopFocus()` 会复位它），只有番茄模式才归零。`PlatformControlTests::menuStopKeepsPomodoroStreakOutsidePomodoroMode` 覆盖自由专注、主动休息和番茄三种情形。
- **今日专注明细页两处文字看不清**：把 `todayFocus` 纳入对比度门禁并注入记录桩之后，时间轴立刻报出两条真实缺陷——时长读数用 `Theme.accent`（日间 2.07:1）、「已完成」用 `Theme.success`（日间 2.58:1）。改用 `accentInk` / `successInk`。

### 6.2 测试补强

- **`tst_dialog_close_guard.qml`（新增）**：8 个写入表单的「关闭期间不得再提交」集中成一条横向不变量。上一轮只有目标表单有真断言，其余 7 个没有任何用例。逐个摘掉 `submissionClosed` 判断做变异验证，8 条全部转红。新建任务弹窗另有 `resetFields()` 兜底，门禁在那里的可见价值是不在正消失的弹窗上闪校验错误，用例按这个口径断言。
- **设置 Esc**：原用例在修复前的文件上同样通过——侧栏首个分类按钮本就会拿到焦点，Escape 照常冒泡。补上「刚打开时焦点必须落在 contentItem 子树内」这条前提断言；同时摘掉 `forceActiveFocus()` 和导航按钮的 `activeFocusOnTab` 时用例转红，恢复 `forceActiveFocus()` 后转绿，`onOpened` 里那行的作用由此可证。**原报告描述的「首次打开 Esc 关不掉」在离屏环境未复现**，按未复现的潜在风险记录，不宣称已实测修复。
- **撤销窗口内的统计口径**：仪表盘与今日页各补一条，验证任务数、完成率按可见列表预览，专注时长仍取已保存记录，撤销后回到数据库口径。摘掉预览代码两条均转红。仪表盘「今日任务完成」卡补 `objectName` 以便定位。
- **对比度门禁**：补上 `todayFocus` 页，并注入专注记录桩，让时间轴真正渲染出行再体检（不注入时这页只有空状态）。知识缺口页目前仍只扫到空状态——门禁没有注入缺口服务，这是已知的覆盖边界。
- **启动失败窗口**：`tst_startup_error_window.qml`（新增）验证它不依赖任何业务服务就能实例化、给出数据目录、路径只读可选中，拿不到可写位置时不留空白框。
- **测试文件归位**：`tst_focus_picker_keyboard.qml` 里混着圆环重绘和里程碑文案两件无关的事，拆成 `tst_focus_ring_theme.qml` 与 `tst_milestone_dialog_duration.qml`。

### 6.3 补齐的产品信息

- **启动失败窗口给出数据目录**：新增 `DatabaseManager::defaultDatabasePath()` 作为单一来源，`main.cpp` 把所在目录注入失败窗口。迁移快照 `pomodoro_backup_*.db` 与数据库同目录，给出目录即同时指出两者位置。`CoreLogicTests::defaultDatabasePathIsTheOneInitializeActuallyOpens` 在 `QStandardPaths` 测试模式的沙箱目录里真的跑一次无参 `initialize()`，再回读实际连接的数据库文件，把两条路径钉成同一个。只断言「路径长得像应用数据目录下的 pomodoro.db」不够：`initialize()` 哪天换条路径，窗口就会指向空目录，而那种断言照样绿。让 `initialize()` 自己拼另一个文件名可使该用例转红。

### 6.4 写进业务规则的约束

- 备份偏好白名单外的类型是**整份拒绝**而非跳过该键；新增设置项必须是标量，列表语义存分隔字符串。现有设置全是标量，对已有备份无影响，但将来新增 `QStringList` 类设置而不同步白名单，会让之后产生的每一份备份都恢复不回来。
- CSV 的单引号前缀是 Excel 的文本转义约定，Numbers 与 Google Sheets 会原样显示——已接受的代价，不是缺陷。
- 结束专注在所有入口同口径；写入表单关闭期间阻断提交（新增表单需同步补 `tst_dialog_close_guard.qml`）；撤销窗口内任务数按可见列表预览而历史读数不回退。
