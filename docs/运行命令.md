# 运行命令（VSCode 终端）

在项目根目录 `/Users/zerionlito/code/番茄todo` 下执行。配置必须使用目标 Qt SDK 自带的 `qt-cmake`。

> `<qt-cmake>` 替换成目标 Qt SDK 的完整工具路径。本机已验证路径为
> `/Users/zerionlito/Qt/6.9.0/macos/bin/qt-cmake`。当前 Homebrew Qt Quick 框架最低要求
> macOS 26，不用于正式部署。配置阶段会打印 `使用的 Qt: <版本> @ <路径>`，照着确认一次再往下走。

## Debug 构建（日常开发）

构建完成后会自动把最新应用包同步到固定启动入口 `/Applications/番茄Todo.app`。

```bash
<qt-cmake> -B /tmp/pt-build -S .
cmake --build /tmp/pt-build -j8
```

可选开关：

```bash
# 跳过自动部署（审计/CI/临时目录构建用，避免覆盖固定入口）
<qt-cmake> -B /tmp/pt-audit -S . \
      -DPOMODORO_TODO_DEPLOY_LOCAL=OFF

# 关闭 QML 调试钩子（非调试期建议关闭，部署包更干净）
<qt-cmake> -B /tmp/pt-build -S . \
      -DPOMODORO_TODO_ENABLE_QML_DEBUG=OFF
```

## Release 构建

```bash
<qt-cmake> -B /tmp/pt-release -S . \
      -DCMAKE_BUILD_TYPE=Release -DPOMODORO_TODO_DEPLOY_LOCAL=OFF
cmake --build /tmp/pt-release -j8
```

产物：`/tmp/pt-release/PomodoroTodo.app`。

## 测试

```bash
# 全套（15 个目标：C++、资源清单与 QML 测试）
# 每个测试目标在 CMake 中另有 30/90/180 秒 watchdog；这里的 240 秒是旧构建缓存的最后护栏。
QT_QPA_PLATFORM=offscreen QT_QUICK_CONTROLS_STYLE=Basic \
  ctest --test-dir /tmp/pt-build --output-on-failure --timeout 240

# 只跑单个测试目标
/tmp/pt-build/PomodoroTodoTests        # 服务层主套件
/tmp/pt-build/CoreLogicTests           # 核心逻辑边界补充
/tmp/pt-build/RobustnessTests          # 健壮性与性能
/tmp/pt-build/CountdownServiceTests    # 倒计时服务
/tmp/pt-build/GoalServiceTests         # 长期目标服务
/tmp/pt-build/BackupServiceTests       # 备份与恢复
/tmp/pt-build/TimingRobustnessTests    # 计时健壮性（休眠/改钟）
/tmp/pt-build/PlatformControlTests     # 菜单栏与通知（平台无关层）
/tmp/pt-build/FontAssetsTests          # 字体资源
/tmp/pt-build/WallpaperAssetsTests     # 壁纸资源
/tmp/pt-build/ShaderAssetsTests        # Shader 资源

# 只跑 QML 测试
ctest --test-dir /tmp/pt-build -R PomodoroTodoQmlTests --output-on-failure

# 按名字过滤 C++ 用例（Qt Test 原生参数）
/tmp/pt-build/PomodoroTodoTests interruptedFocusRestoresPausedAndKeepsProgress
```

## 常见问题

- **改了 QML 但界面像旧版**：先清 qmlcache 再启动：
  `rm -rf ~/Library/Caches/PomodoroTodo/PomodoroTodo/qmlcache`
- **可选 QML 静态检查**：
  `<Qt SDK>/bin/qmllint -I qml qml/*.qml qml/views/*.qml qml/components/*.qml`
