## Debug 构建（日常开发）

构建完成后会自动把最新应用包同步到固定启动入口 `/Applications/番茄Todo.app`。

```bash
<qt-cmake> -B /tmp/pt-build -S .
cmake --build /tmp/pt-build -j8
```

部署脚本 `cmake/DeployLocalApp.cmake` 的顺序是：复制到暂存目录 → 校验主二进制存在 →
旧包改名备份 → 原子 rename 换上新包 → 清理备份并刷新 `lsregister`。任一步失败都会把旧包放回原位，
不存在「先删旧包再复制」的空窗期。

可选开关：

```bash
# 跳过自动部署（审计/CI/临时目录构建用，避免覆盖固定入口）
<qt-cmake> -B /tmp/pt-audit -S . \
      -DPOMODORO_TODO_DEPLOY_LOCAL=OFF

# 打开 QML 调试钩子（默认 OFF；只有要跑 qmlprofiler / QML 调试器时才需要）
<qt-cmake> -B /tmp/pt-build -S . \
      -DPOMODORO_TODO_ENABLE_QML_DEBUG=ON
```

> **不要在同一个构建目录里混用这两种配置。** `POMODORO_TODO_DEPLOY_LOCAL` 是 CMake cache 变量，
> 值会持久化在构建目录里：在 `/tmp/pt-build` 先跑过一次 `=OFF`，之后不带该参数重新配置也不会恢复成 `ON`，
> `deploy-local-app` 目标不会被创建，部署会**静默失效**。约定：部署用 `/tmp/pt-build`，审计/测试用 `/tmp/pt-audit`。

## Release 构建

```bash
<qt-cmake> -B /tmp/pt-release -S . \
      -DCMAKE_BUILD_TYPE=Release -DPOMODORO_TODO_DEPLOY_LOCAL=OFF
cmake --build /tmp/pt-release -j8
```

产物：`/tmp/pt-release/PomodoroTodo.app`。

## 测试

规模（2026-08-10 实测，Qt 6.9.0）：**18 个 ctest 目标全绿，约 75 秒**。
16 个 C++ 目标共 378 个测试函数，`PomodoroTodoQmlTests` 一条覆盖 `tests/qml/` 的 43 个
`tst_*.qml` 文件、550 条断言函数（约 56 秒，占总时长四分之三）；
另有 `QmlLintGate` 一条 QML 静态检查门禁（约 0.6 秒）。

```bash
# 全套
# 每个测试目标在 CMake 中另有 30/90/180 秒 watchdog；这里的 240 秒是旧构建缓存的最后护栏。
QT_QPA_PLATFORM=offscreen QT_QUICK_CONTROLS_STYLE=Basic \
  ctest --test-dir /tmp/pt-audit --output-on-failure --timeout 240

# 只跑单个测试目标（直接跑二进制时同样要带 offscreen，否则会拉起 cocoa 平台插件弹窗）
export QT_QPA_PLATFORM=offscreen QT_QUICK_CONTROLS_STYLE=Basic
/tmp/pt-audit/PomodoroTodoTests        # 服务层主套件（177）
/tmp/pt-audit/CoreLogicTests           # 核心逻辑边界补充（17）
/tmp/pt-audit/RobustnessTests          # 健壮性与性能（10）
/tmp/pt-audit/CountdownServiceTests    # 倒计时服务（16）
/tmp/pt-audit/GoalServiceTests         # 长期目标服务（35）
/tmp/pt-audit/BackupServiceTests       # 备份与恢复（24，约 8 秒，真实文件 I/O）
/tmp/pt-audit/TimingRobustnessTests    # 计时健壮性（休眠/改钟）（10）
/tmp/pt-audit/PlatformControlTests     # 菜单栏与通知（平台无关层）（17）
/tmp/pt-audit/MacNotificationBackendTests  # 通知后端（macOS 原生层）（3）
/tmp/pt-audit/ShortcutRegistryTests    # 快捷键注册表（默认/覆盖/冲突/单键/全局注册，用假后端）（18）
/tmp/pt-audit/MacGlobalHotkeyTests     # 全局热键键码翻译（Carbon，不注册真实热键）（6）
/tmp/pt-audit/FontAssetsTests          # 字体资源（4）
/tmp/pt-audit/WallpaperAssetsTests     # 壁纸资源（1）
/tmp/pt-audit/ShaderAssetsTests        # Shader 资源（1）
/tmp/pt-audit/SoundAssetsTests         # 音效资源（4）
/tmp/pt-audit/QmlResourceManifestTests # QML 资源清单守门（源文件与 qrc 一致性）（2）

# 只跑 QML 静态检查门禁（unqualified 与 layout-positioning 零容忍）
ctest --test-dir /tmp/pt-audit -R QmlLintGate --output-on-failure

# 只跑 QML 测试
ctest --test-dir /tmp/pt-audit -R PomodoroTodoQmlTests --output-on-failure

# 按名字过滤 C++ 用例（Qt Test 原生参数）
/tmp/pt-audit/PomodoroTodoTests interruptedFocusRestoresPausedAndKeepsProgress
```

> QML 测试红线：
> - **不要断言 `item.visible === true`**。离屏环境下 `visible` 的级联判定不可靠，
>   改为断言业务属性、`opacity` 或宽高。需要表达「没有可说的」时，让文案返回空串再断言文案，
>   比靠 `visible` 藏起来更稳。
> - **日期一律走逻辑日**（`dayStartHour`，默认 4 点）。用 `new Date()` 的物理日期写用例，
>   白天跑碰巧过、凌晨 4 点前必红——已经有一条用例这样漏网过。
> - **`Popup` 的 `onClosed` 在离屏环境不投递**。要验证「关闭后重置」这类行为，
>   直接断言重置函数本身，不要绕 `close()`。

## 常见问题

- **改了 QML 但界面像旧版**：先清 qmlcache 再启动：
  `rm -rf ~/Library/Caches/PomodoroTodo/PomodoroTodo/qmlcache`
- **构建完了 `/Applications/番茄Todo.app` 没更新**：多半是这个构建目录里 cache 还留着
  `POMODORO_TODO_DEPLOY_LOCAL=OFF`。用 `grep DEPLOY_LOCAL <builddir>/CMakeCache.txt` 确认，
  重新配置时显式传 `-DPOMODORO_TODO_DEPLOY_LOCAL=ON`，或换一个干净的构建目录。
- **可选 QML 静态检查**（覆盖含 `components/settings/` 在内的全部 QML）：
  ```bash
  <Qt SDK>/bin/qmllint -I qml \
    qml/*.qml qml/views/*.qml qml/components/*.qml qml/components/settings/*.qml
  ```
  **它现在是门禁**：ctest 条目 `QmlLintGate` 对 `unqualified` 与 `Quick.layout-positioning`
  零容忍（两者均已清零，2026-08-08 实测），只豁免 `missing-property`（4 条，工具推导限制）
  与 `use-proper-function`（6 条，项目既定的回调注入模式）。上面那条手工命令用于查看
  全部告警；判据以 `QmlLintGate` 为准。
  不要用 `pyside6-qmllint`——本机未安装，且它来自本项目明确不用于部署的 PySide6 工具链。
