# 当前业务规则

本文记录当前实现必须保持的业务边界与跨层约定。功能总览见 [README](../README.md)，构建和测试见 [运行命令](运行命令.md)，待办与未采纳决策见 [计划索引](../plans/README.md)。

## 专注、日期与任务

- 专注规则统一定义在 `src/services/FocusSessionRules.h`：单段有效门槛为 3 分钟；`validPomodoroCountExpr` 只计番茄模式自然到点的有效记录，`focusedSecondsExpr` 累计两种模式的有效时长。自由计时不折算番茄数。
- 任务预计用时、今日专注目标、长期目标以分钟计量；输入共用 `DurationFieldPair.qml`，格式化共用 `qml/Duration.js`。任务实际投入从专注记录派生，达到预计用时可自动完成任务。
- 专注与任务归属使用逻辑日，默认从凌晨 4 点开始。日期计算统一走 `LogicalDay`；QML 必须在日界变化时更新可观察的日期状态，不能依赖 `new Date()` 自动触发绑定重算。课表使用自然星期，不套用专注记账日期。
- 今日任务按完成状态、当天 `display_order`、创建时间、编号稳定排序。新建、结转和改期任务追加到目标日末尾；重排必须提交当天完整任务集合，不能重复或漏项。拖动期间保持模型稳定，松手后再写入顺序。
- 每日例行生成必须幂等，不重复生成，不补齐所有历史日期；当天删除过的实例不能因刷新而复活。
- 手动补录记为自由计时。新增和修改都拒绝未来时间、重叠区间、低于有效门槛的记录；不能修改正在进行的会话。

### 主动休息与超长自由专注

- 主动休息入口位于今日任务页，仅在计时器空闲时可开始。它与番茄休息是不同阶段，均不写 `focus_sessions`，不增加番茄数、今日专注或长期目标进度。
- 主动休息支持暂停、继续和结束；重启后只恢复为暂停状态，不把离线经过时间补入计时。结束后返回今日任务页。
- 自由专注超过提醒阈值时，结束前确认记录或丢弃，并可向下修正时长。未编辑时保留原始秒数；编辑后按整分钟处理，最少 3 分钟，不能超过实际计时时长。前端与服务层都校验。
- 修正记录的结束时间必须等于开始时间加修正时长，避免区间与时长矛盾，阻挡后续补录。保存失败时保留当前会话供重试。

## 长期目标与奖励

- 目标必须绑定有效科目；按科目和起始日期从专注记录派生投入分钟、进度、预测和月历热力，不冗余存储累计进度。课表与休息没有专注记录，因此不参与目标累计。
- 奖励通过全局信号送达，避免用户停留在专注页时看不到进度反馈。目标页承担列表、详情、100 格进度与热力展示。
- 25/50/75/100% 里程碑用 `fired_milestones` 位掩码记录哪些档位已触发。普通进度回退不清除奖励位，重新达到旧档位不重复庆祝；一次跨多档只通知最高档。
- 修改目标值、科目或起始日会改变进度定义，按新定义重新对齐奖励位；只改标题或截止日保留奖励位。目标字段与奖励状态在同一事务提交，避免半保存。
- `achieved_at` 记录首次达成时间，进度回退不抹除。新建目标会对齐已有历史进度，不能在下一次专注结束时把旧投入当成新里程碑补弹。
- 沉浸模式压制庆祝弹窗；`reduceMotion` 与 `soundEnabled` 控制动画和音效降级。统计页等级与已达成列表已按产品决定撤回，目标维度导出尚未实现，二者都不是当前交付承诺。

## 课表

- `schedule_entries` 与 `schedule_periods` 独立于任务和例行任务。课表按星期、时段、周次范围及单双周循环，没有完成状态，不生成任务，不接专注计时，不参与统计与目标进度。
- 服务层负责存储、给定周次的查询和冲突判断；`qml/ScheduleWeeks.js` 负责日期与学期周次换算，避免服务层依赖界面设置。
- 时间轴按真实时长排布，节次模式按等高节次排布，两者共用起止分钟数。冲突必须同时具备时间重叠和实际共同生效周；仅周次范围交叠还不够。
- 周次范围被单双周规则完全排除时拒绝保存。视觉泳道按显示区间分配，短块放大或映射到节次后也不能互相盖住；未落入节次或被周末开关隐藏的条目要明确提示。
- 课表设置先校验全部输入，再保存节次、批量同步学期设置；设置写入失败时补偿回滚旧节次，回滚失败单独报告。这是数据库与设置文件之间的补偿流程，不是跨文件原子事务。
- QSettings 写入失败必须恢复旧缓存及原先不存在的键，不能仅重建对象；成功落盘后才发成功变更信号，失败后允许重试。读取失败不能伪装为空列表。

## 数据安全与跨层交互

- schema 版本以 `DatabaseManager::kCurrentSchemaVersion` 为准。迁移不能只信版本号，还要检查结构，补齐缺失的表或列；已有但不合法的课表结构须报错。空节次表重新打开时补默认节次，失败必须整体回滚。
- 课表主键必须具备 SQLite 自动生成整数编号的语义；启动与备份检查共用校验。v13 备份必须有合法课表表、约束和主键，旧版本备份允许缺表，由恢复后的迁移补齐。
- 旧备份兼容性按 schema 版本判断，不能把后续新增或懒建的表无条件加入所有版本的必需表清单。增加任务列时同步检查 `migrateToVersion5` 的整表重建语句与列清单，避免重建丢数据；迁移测试要覆盖带旧数据的数据库。
- 备份拒绝 Trigger、View、虚拟表等非预期数据库对象；恢复设置仅写回 `AppSettings::ownedSettingGroups()` 声明的顶层分组，兼容快捷键等动态子键。新增设置分组必须同步所有权清单。
- 新恢复点创建并提交成功后再清理旧快照，失败不能提前消耗最后的恢复机会。恢复失败需要回滚并重新打开数据库；数据库替换期间阻断界面操作、快捷键与直接动作分发。
- CSV 导出、备份和恢复的耗时工作放在工作线程。数据库连接不跨线程共享，导出线程使用独立只读连接；全部导出的多个文件读取同一事务快照。导出期间的关闭、取消、退出语义必须一致。
- 主连接的锁等待设置、后台连接与事务边界协同维护；不能用界面假成功掩盖写入失败。失败状态要保留可重试入口，与正常空数据区分。
- macOS 原生实现放在 `src/platform/macos`；业务服务依赖平台无关抽象。跨服务信号在组装层接线，避免目标服务与计时器形成循环依赖。
- 本机部署使用暂存包、旧包备份与原子切换，失败还原旧包。具体命令与二进制一致性校验见 [运行命令](运行命令.md)，协作约束见 [AGENTS.md](../AGENTS.md)。

## 界面与验证约定

- 使用现有 `Theme.qml` 语义颜色与 Qt Quick Controls 风格；独立弹窗也须接管 `palette`，保证浅深主题中的正文、占位文字、选区及输入边界可读。
- 玻璃效果只用于导航、浮动工具栏、弹窗与重要控制，内容卡保持清晰；业务内容位于光学层之上，效果缺失或关闭时提供可读的半透明纯色降级。不可见时停止效果更新，动效支持 `reduceMotion`。
- 调低 `MultiEffect.blurMax` 会同时改变阴影外观，不能把它当成无副作用的性能参数。性能改动先提供测量，不能仅凭组件数量决定虚拟化或切换渲染实现。
- 非字面量 `text` 绑定必须显式声明 `textFormat`，避免任务标题等字符串被 AutoText 猜成富文本，由 `QmlTextFormatGate` 检查。
- `QmlLintGate` 负责静态告警；类型推导限制只允许在具体表达式旁注明原因并局部压制，不能全局放宽类别或数量。
- 每个 QML 测试条目通过 `FAIL_REGULAR_EXPRESSION` 拦截 `Unable to assign`、`TypeError`、`is not a function` 与 `Binding loop`。确需触发告警的用例只调整自身条目，保留其他检查。
- 运行时门禁只能覆盖实际执行的路径。弹窗测试需真正打开并执行交互，`tst_dialog_smoke.qml` 提供基础覆盖；不能把仅实例化组件当成完整覆盖。
- 注入的服务替身缺方法或属性时，先检查可调用性，再显式归一化布尔和数值；仅检查对象非空不能避免运行时类型错误。
- 自动验证使用离屏平台，不启动应用窗口；以状态等待代替猜测时长的固定睡眠，测试在初始化阶段复位数据库，避免单个断言失败污染后续用例。具体命令与测试约定见 [运行命令](运行命令.md)。
