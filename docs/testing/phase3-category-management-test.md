> **勘误（照本文修改代码会改错方向）**：
> - 「有关联任务的科目不可删除」与**现行实现相反**。`CategoryManager.cpp` 的
>   `canDeleteCategory()` 明确注释「任务关联不是删除阻断条件」，`deleteCategory()` 会**先解除任务关联再删科目**；
>   真正的阻断条件只有「预设科目不可删除」（`is_preset = 1`）。
> - 「`ctest` 通过，2/2 tests passed」是当年的规模。现在是 **15 个 ctest 目标**、
>   298 个 C++ 测试函数 + 448 条 QML 断言函数。
> - 正文里的 `cmake --build build` / `--test-dir build` 用的是仓库内 `build/` 目录。
>   现行规则是**构建目录必须放在仓库外**（见 `AGENTS.md`）。
> - 科目的历史归属此后加了 v9 快照列（`category_*_snapshot`）：删除科目不再抹掉历史统计，
>   本文写作时还没有这套机制。
