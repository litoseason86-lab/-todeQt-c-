## 最容易被误读的一点：那 1307 个未勾选的复选框

`plans/` 里共有 **1307 个 `- [ ]` 未勾选项、261 个已勾选项**。
**这个比例不代表 83% 的工作没做。** 实际情况是：这些计划里描述的功能**绝大多数早已上线**
（番茄与自由双模式、专注历史、科目管理、CSV 导出、统计时间范围与趋势、每日例行、逻辑日、
沉浸全屏、设置中心、背景主题与玻璃化、专注环重做等，都在当前应用里跑着），
只是执行时没有回头逐条勾选复选框。

**结论：不要把这里的未勾选项当成 backlog，也不要照着重新实现。**
判断某个功能今天是什么状态，唯一可靠的做法是**读代码**，或看下面这两处：

- `README.md` —— 当前功能总览
- `plans/README.md` —— 当前唯一在维护的执行状态索引（未执行的只剩编号 025–031）
